Sprag

조회는 가벼운 모델에게,
판단은 메인 모델에게

Sprag는 Claude Code와 Codex에 붙는 위임 계층입니다. 파일 찾기와 테스트 실행 같은 일은 Haiku나 Sonnet 서브에이전트에 넘기고 설계와 원인 진단은 메인 모델에 남깁니다. 어느 일을 넘길지는 내 세션 기록에서 정하고 규칙마다 하나씩 승인을 받습니다.

npm i -g sprag-cli
GitHub에서 보기 sprag.io

Node.js 20 이상에서 동작합니다. 계정이나 API 키는 필요하지 않습니다.

Getting started

설치한 날부터 이렇게 달라집니다

  1. npm i -g sprag-cli 를 실행하면 훅과 상태줄, 추천 규칙이 모든 프로젝트에 설정됩니다. 프로젝트마다 따로 설정할 것은 없습니다.
  2. 아무 프로젝트에서나 Claude Code를 열고 평소처럼 일합니다. 규칙에 맞는 일은 알아서 서브에이전트로 넘어갑니다.
  3. 상태줄을 봅니다. 위임 현황과 캐시 적중률, 컨텍스트 크기가 보이고 문제가 생기면 경고 칩이 맨 앞에 뜹니다.
🔀 Routing opus→sonnet ×67 · fable→sonnet ×26 · opus→haiku ×25 🧠 Cache hit 98.8% · ⏳ Cache expires 59:46 · 📦 Ctx 47% of 1M

쓰던 상태줄이 있으면 함께 표시할지, 바꿀지, 그대로 둘지 설치 중에 묻습니다. sprag uninstall 을 실행하면 설치 때 더한 것을 모두 지웁니다.

How it works

모델을 바꾸지 않고 일을 나눕니다

Claude Code와 Codex는 프롬프트마다 모델을 바꿀 수 없습니다. 그래서 Sprag는 메인 세션에 규칙을 주고, 규칙이 모델과 effort를 고정한 서브에이전트에 일을 넘기게 합니다.

1답이 어디에 있는가: 파일과 명령 출력에서 답이 나오는 조회는 가벼운 모델로도 충분합니다.
2틀리면 바로 드러나는가: 테스트나 종료 코드가 잡아 주는 일만 내립니다. 설계와 원인 진단, 보안은 메인 모델에 남깁니다.
3실제로 몇 번 틀렸는가: 내 기록에서 측정한 오류율을 규칙마다 붙이고, 맞지 않게 되면 일을 메인 모델로 되돌립니다.

Privacy

세션 기록은 내 컴퓨터 밖으로 나가지 않습니다

○분석은 로컬에서 실행합니다. 추가 모델 호출이나 API 키가 필요하지 않습니다.
○Sprag는 사용자가 고른 모델을 바꾸지 않습니다. 메인 세션은 그대로 두고 서브에이전트만 띄웁니다.
○CLI는 사용자를 알아볼 수 있는 데이터를 보내지 않고 계정도 요구하지 않습니다.

팀 기능을 켰을 때 무엇이 올라가는지는 Sprag이 보내는 데이터에 항목별로 적어 두었습니다.

자주 묻는 질문

Codex에서도 쓸 수 있나요?

쓸 수 있습니다. Codex가 설치되어 있으면 npm i -g sprag-cli 가 Codex도 함께 설정합니다. 설치 후에는 Codex의 /hooks 에서 새 훅을 신뢰해 주셔야 합니다.

가벼운 모델이 틀리면 어떻게 되나요?

서브에이전트가 돌려준 결과는 메인 모델이 검토한 뒤에야 완료로 인정합니다. 같은 오류가 두 번 나거나 답이 갈리면 메인 모델이 이어받습니다.

Bedrock이나 Vertex, LiteLLM 뒤에서도 동작하나요?

동작합니다. 게이트웨이별 설정과 주의할 점은 게이트웨이 문서에 정리했습니다.

버그는 어디에 알리나요?

GitHub 이슈에 남겨 주세요. 사내망처럼 GitHub에 접속하기 어려우면 터미널에서 sprag feedback "내용" 으로 바로 보낼 수 있습니다.

AI 개발 도구를 다루는 유튜브 채널 DeepPulse에서 만들고 매일 씁니다. 문의는 support@sprag.io로 보내 주세요.
